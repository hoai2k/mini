# Bubble Chat

A video chat in the browser with face effects and minigames, built on the
shared mini-rooms relay (see [`../MULTIPLAYER.md`](../MULTIPLAYER.md)). Work in
progress: the app itself is being built.

- Image requests: [`design/image-requests.md`](design/image-requests.md),
  generated from `design/source/build_requests.py`.
- Drop box for delivered art: [`intake/`](intake/README.md).
