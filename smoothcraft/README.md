# Smoothcraft

A Minecraft Java Edition mod (Fabric, Minecraft 26.3) that renders the world
as smooth shapes instead of cubes: terrain melts into continuous rolling
surfaces, mobs become rounded 3D models of their voxel selves, every surface
gets a physically based material, and the 16 px textures are replaced by
high-resolution realistic ones.

Work in progress: the image requests are written; the mod itself is being
built. This README is completed when it lands.

- Image requests: [`design/image-requests.md`](design/image-requests.md)
  (tier 1, the common things), [`design/image-requests-blocks.md`](design/image-requests-blocks.md),
  [`design/image-requests-entities.md`](design/image-requests-entities.md),
  machine-readable [`design/image-requests.json`](design/image-requests.json).
  Generated by `design/source/build_requests.py` from
  `design/source/vanilla_textures.tsv` (written by `tools/list_vanilla_textures.py`).
- Reference images to paint over: `python3 tools/make_references.py` writes
  upscaled vanilla textures from your own Minecraft jar to
  `local/smoothcraft/references/` (outside Git).
- Drop box: [`intake/`](intake/README.md).
