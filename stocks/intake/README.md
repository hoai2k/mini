# Stocks intake

Drop files for Stocks (the `stocks/` folder) here and ask for them to be
integrated: notes, a list of symbols to build in, exported price or dividend
data to check against. Nothing in this folder is published.

Symbols join the built-in list through `../tools/snapshot.mjs` (see the
README), not by hand-editing `../app/data/`. Afterwards the folder is emptied,
leaving only this README. The repository-wide rules are under "Intake" in
[`CLAUDE.md`](../../CLAUDE.md).
