# Percy Jackson concept art

All 19 requests generated with the built-in image generation tool. These are planning concepts in the cartoon heroes in an ornamental world direction.

The [request document](../image-requests.md) contains the briefs. [generation.json](generation.json) records prompts, reference files, original dimensions, delivered dimensions and checksums. The delivered PNGs are resized copies of the smaller tool outputs.
