# Percy Jackson concept art

The 19 round-1 images establish the cartoon heroes in an ornamental world direction. Round 2 adds 27 images, including the voxel hero and monster sheets and three game artwork files. All were generated with the built-in image generation tool.

The [request document](../image-requests.md) contains the briefs. [generation.json](generation.json) records prompts, reference files, original dimensions, delivered dimensions and checksums. [generation-round-2.json](generation-round-2.json) records the second-round prompts, references and targeted corrections. The delivered PNGs are resized copies of the smaller tool outputs.
