# Percy Jackson (planning)

A possible game based on Rick Riordan's *Percy Jackson and the Olympians*,
starting with *The Lightning Thief*. Nothing is built yet and nothing in this
folder is published.

- [`reference/`](reference/README.md): how Percy, Annabeth and their world have
  been represented in books, comics, film, TV, stage and games, grouped into
  style families to choose an art direction. The images belong to their owners
  and are kept here as private reference only, never as game assets.

When the game itself starts, this folder gets the usual `intake/`, `publish.sh`,
Pages workflow step and library card.
