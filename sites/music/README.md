# Shared music

Recordings that belong to the band sites rather than to a game. Drop a file
here under the exact name its page expects and the page's player finds it;
each band site also accepts the same file in its own `music/` folder, and
looks there first. `sites/publish.sh` deploys this folder to
`/mini/sites/music/`.

Neither band site plays anything from here at the moment: both track lists
link out to streaming instead, with in-page playback switched off rather
than removed (`player.js` stays put, and each page says how to re-enable
it). If it comes back, these are the files it expects:

- `Moonlit Go-go Interlude.mp3` — Space Tiber
- `Matchpoint Midnight.mp3` — Charlie's Girl Dolls
