Visitor stats

Who is finding the sites under /mini/sites/, and from where. One counter covers all of them: the overview is everything together, and each tab narrows the same dashboard to one site.

What this records

Kept, per visit
  • Country, derived from the IP address and then discarded
  • Referrer — the page that linked here
  • Browser and operating system
  • Screen width and language
  • Which page, and when
Never kept
  • IP addresses
  • The full User-Agent string
  • Any tracker or advertising ID
  • Cookies — none are set, by us or by the counter
  • Anything a visitor did on the page: no clicks, no scrolling

Counting is done by GoatCounter, whose privacy page is the authority on the two lists above, not this one.

Reading it honestly

  • Your own visits are not counted. The counter skips localhost, private addresses and file://, so the numbers are other people rather than you checking a page you just changed. It also means a local preview can never confirm that counting works; only the deployed site can.
  • It undercounts. Ad blockers block gc.zgo.at, and those visits go unrecorded with no sign on either end. Treat every number as a floor.
  • There is no history before switch-on. Pages kept no log, so there is nothing to backfill. Day one is the day the code lands.
  • Country is coarse and sometimes wrong. It comes from an IP database, and a VPN reports wherever its exit node is.
  • The games are counted separately. This covers /mini/sites/ only. Hopper, at /mini/hopper/, has no counter on it.
