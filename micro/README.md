# Micro

Video games where you play as microscopic creatures. Still at the research and
prototype stage.

- [`research/`](research/) is a cited research atlas of four scale bands
  (mites, water-film animals, large protists, small cells), their habitats,
  visual styles and real biological "powers". Its pages are built by
  `research/build.py`.
- [`design/`](design/) holds design documents and the image requests
  ([`design/image-requests.md`](design/image-requests.md), generated by
  `design/source/build_requests.py`).
- [`prototypes/`](prototypes/) holds small playable experiments, published at
  https://hoai2k.github.io/mini/micro/prototypes/ in the prototype archive,
  behind the invite gate.
- [`intake/`](intake/README.md) is the drop box for delivered art.

## Checks

```bash
python3 micro/design/source/build_requests.py --check
```

```bash
node micro/prototypes/check.mjs
```
