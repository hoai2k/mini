# Third art round

Two C14 replacements generated with built-in imagegen, using the previously
delivered cliff, cottage, sailor and night scene as references.

- `cliff-face-tall-2`: 1400 × 3600, alpha PNG, bottom-centre anchor. The cliff
  keeps its width up to the grassy top. Production sizing crops the small
  fringe above the first continuous painted top row so the house has a level
  edge to stand on. The original generated image and exact crop are retained.
- `ending-dark-3`: 2560 × 1440, opaque PNG. The modest stone cottage, dark
  window and lit doorway silhouette sit inside the curtain margins; the
  sailor throws a stone into the bay from the foreground quay.
