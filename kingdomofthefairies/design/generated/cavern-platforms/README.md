# Painted cavern platform supports

The original and tinted rock faces replace the gradient polygons and vertical strips beneath the cavern’s floor platforms, including Dark Pools. The existing ledge rims stay on the walkable surface. Rock faces extend below the stage, with overlapping broad sections on very long floors. Physics, pools and landing surfaces are unchanged.

Generated with the built-in image_gen tool using cavern.webp and cavern-ledge.webp as visual references. Exact prompts, source paths and alpha-bound crops are in generation.json. Native transparent PNGs are retained in source/. prepare_cavern_platforms.py crops and resizes them to lossless 720 × 480 WebPs without repainting.

Verified cavern-art alignment, 51 film tests, both legacy five-act suites, animation, sailor-motion, walking, theme and asset loading. Reviewed Dark Pools in both looks at all three film-effect settings, including hanging, shaking, falling and shattered stalactites. The browser check requires painted supports; no procedural support shape remains.
